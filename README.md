# gestion de la calidad

Proyecto de gestión de la calidad

## Useful commands

```bash
# Install pnpm
npm install -g pnpm@latest

# Install dependencies
pnpm install

# Start apps
pnpm run dev

# Add shadcn/ui components
pnpm run ui add table pagination sidebar avatar

# Add package to specific package
pnpm --filter @una-gc/backend add dotenv

# Add package as a dev dependency
pnpm --filter @una-gc/backend add -D typescript

# Generate prisma client
pnpm run prisma

# Build apps
pnpm run build
```
