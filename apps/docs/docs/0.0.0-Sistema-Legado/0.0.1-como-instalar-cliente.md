# 0.0.1 Instalación del Cliente

| Repositorio GitHub | Enlace                                   |
| ------------------ | ---------------------------------------- |
| G_Calidad          | https://github.com/calidadcoto/G_Calidad |

Esta guía explica cómo configurar y construir el cliente con las versiones correctas de Node.js. Se recomienda utilizar [nvm](https://github.com/nvm-sh/nvm) para gestionar las versiones de Node.js.

## Instalación de dependencias

Para instalar las dependencias (`node_modules`), necesitarás usar Node.js 18.17.0 y Yarn:

```bash
nvm install 18.17.0
nvm use 18.17.0

# Instalar Yarn globalmente
npm install --global yarn
yarn install --ignore-engines
```

## Construcción del cliente

Una vez que las dependencias estén instaladas, cambia la versión de Node.js a 12.13.0 y construye el cliente:

```bash
nvm install 12.13.0
nvm use 12.13.0
npm run build
```

## Ejecución del cliente en local

Para ejecutar el cliente en tu entorno local, debes tener instalado Node.js versión 12.13.0. Sigue estos pasos:

1. Asegúrate de tener la versión correcta de Node.js:

   ```bash
   node -v  # Debe mostrar v12.13.0
   ```

2. Si necesitas cambiar a la versión 12.13.0, puedes usar nvm (Node Version Manager):

   ```bash
   nvm install 12.13.0
   nvm use 12.13.0
   ```

3. Instala las dependencias del proyecto:

   ```bash
   npm install
   ```

4. Inicia la aplicación cliente:

   ```bash
   npm run start
   ```

5. La aplicación debería estar disponible en tu navegador, normalmente en http://localhost:3000 (o el puerto que esté configurado).

> **Nota**: Esta versión específica de Node.js (12.13.0) es obligatoria para garantizar la compatibilidad con todas las dependencias del proyecto.
