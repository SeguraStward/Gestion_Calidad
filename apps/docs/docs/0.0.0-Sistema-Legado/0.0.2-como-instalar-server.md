# 0.0.2 Instalación del Servidor

| Repositorio GitHub | Enlace                                   |
| ------------------ | ---------------------------------------- |
| G_Calidad          | https://github.com/calidadcoto/G_Calidad |

Este documento describe cómo instalar y ejecutar el servidor del sistema legado.

## Requisitos previos

- [nvm (Node Version Manager)](https://github.com/nvm-sh/nvm) para gestionar versiones de Node.js

## Pasos de instalación

### 1. Instalar la versión correcta de Node.js

El servidor requiere Node.js versión 18.17.0. Utiliza nvm para instalar y seleccionar esta versión:

```bash
# Instalar Node.js 18.17.0
nvm install 18.17.0

# Usar esta versión para el proyecto
nvm use 18.17.0
```

### 2. Instalar dependencias

Una vez configurada la versión correcta de Node.js, instala las dependencias del proyecto:

```bash
npm install
```

### 3. Iniciar el servidor

Para iniciar el servidor, ejecuta:

```bash
npm run start
```

## Solución de problemas comunes

Si encuentras algún error durante la instalación, verifica:

- Que nvm esté correctamente instalado
- Que estés utilizando la versión 18.17.0 de Node.js
- Que todas las dependencias se hayan instalado correctamente

## Recursos adicionales

Para más información sobre la gestión de versiones de Node.js con nvm, consulta la [documentación oficial de nvm](https://github.com/nvm-sh/nvm#readme).
